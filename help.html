晚自习考勤表

使用说明与注意事项
https://heibai-king.github.io/checkin/

一、用途

用于记录每次晚自习、早操等活动的出勤情况：标记请假人员、记录请假事由、标记未到人员，并自动统计应到与实到人数。每次记录可单独保存，形成历史台账。

二、打开方式

  1. 电脑：使用浏览器打开上述网址即可。
  2. 手机：首次打开后建议添加到主屏幕，之后从桌面图标进入。
    • iPhone：需在 Safari 中打开，点「分享」→「添加到主屏幕」。
    • 安卓 / 鸿蒙：在浏览器菜单中选择「添加到主屏幕」或「添加到桌面」。
  3. 微信内置浏览器与系统浏览器为两套独立存储，同一网址从不同入口打开，数据互不相通。请固定使用同一种方式，建议统一使用桌面图标。

三、使用方法

  1. 选择日期，填写活动名称（如：晚自习、早操）。
  2. 请假人员：点击其右侧「请假 否」，变为「请假 是」，下方自动展开「事由」栏，填写请假原因；不填默认为「无」。
  3. 未到人员：点击「出勤 已到」，变为「未到」。
  4. 页面底部实时统计：总人数、请假、应到、实到、未到。
  5. 备注：点击同学姓名，可填写备注（如「周一晚课」「周五早操」），显示在名字后面；留空则不显示。备注按人保存，跨天保留。
  6. 填写完成后点击「保存本次」，本条记录存入历史记录。
统计口径
应到人数 = 总人数 − 请假人数
实到人数 = 应到人员中实际到达的人数
未到人数 = 应到人数 − 实到人数
请假人员不计入应到，因此不计入未到。

四、数据保存

  1. 所有数据仅保存在使用者本人设备的浏览器中，不上传、不联网同步，其他人无法查看。
  2. 更换设备、更换浏览器、清除浏览器缓存、使用无痕模式，均会导致数据丢失且无法恢复。
  3. 微信内置浏览器与系统浏览器数据独立；同一网址在不同入口打开，数据不互通。
  4. iOS 设备的 Safari 若长期（约七日以上）未访问该页面，本地数据可能被系统自动清除。

五、备份与导出

  1. 建议每次记录完成后，点击「备份」→「导出备份文件（.json）」，保存至微信收藏或手机文件中。
  2. 更换设备时，在新设备打开同一网址，点击「备份」→「导入备份」，选择此前导出的文件即可恢复。
  3. 需要提交或留档时，点击「导出」，生成 CSV 文件（含日期、活动、姓名、备注、请假、事由、出勤），可使用 Excel、WPS 直接打开。
  4. 备份文件仅对应导出它的设备，请勿相互转发，以免覆盖各自数据。

六、名单管理

  1. 默认名单为 50 人，另预留 5 个空位，可直接补填。
  2. 点击「名单」可修改姓名、填写备注、增加或删除人员；姓名留空的行不会显示在点名表中。
  3. 「恢复默认名单」将名单恢复为初始 50 人，历史记录不受影响，自行添加的姓名会被清除。
  4. 名单修改仅在本设备生效，不会同步至其他使用者。

七、隐私说明

  1. 页面存放于公开的静态托管空间，任何获得链接的人均可查看页面内容（仅含姓名，不含学号）。
  2. 页面已设置禁止搜索引擎收录，但链接本身不具备访问权限控制。
  3. 请勿将链接发布至班级以外的公开渠道。
  4. 如不再使用，由仓库所有者删除该页面后，链接随即失效。

八、网络访问

  1. 页面托管于 GitHub Pages，国内部分网络环境（个别运营商、校园网）可能出现访问缓慢或无法打开的情况。
  2. 建议先由一至两人在手机流量下测试，确认可正常访问后再统一发送。
  3. 如加载缓慢，可尝试刷新页面；如持续无法打开，请联系维护人获取离线文件版本。

九、常见问题

打开后空白或一直加载？

先刷新或更换网络重试；仍无法打开，多为当前网络无法访问托管服务器。

更换手机后记录不见了？

数据仅存于原设备浏览器。需在原设备导出备份，再于新设备导入。

同一天保存了两次怎么办？

同一日期与同一活动仅保留一条记录，第二次保存时会提示是否覆盖。

请假的人为什么没有计入「未到」？

请假人员不计入应到人数，因此不参与实到与未到的统计。

「新的一天」会清掉备注吗？

不会。备注按人保存，跨天保留；只会清空当天的请假、事由和出勤。

能否多人共同编辑同一份表？

当前版本为单机版，各使用者数据独立，互不可见。

十、版本与更新

  1. 页面由维护人统一更新，网址保持不变。
  2. 版本更新不影响已保存的记录。
  3. 若发现界面与本说明不一致，请刷新页面（必要时清除缓存）后重试。
  4. 使用中如遇问题，请联系本班负责维护的同学。
